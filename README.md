# Speed Test for AD Robot
# Скрипт замера скорости скачивания

Консольная утилита для тестирования реальной скорости интернет-соединения путем последовательного скачивания файла (например, тяжелого изображения) заданное количество раз.

## Особенности реализации
* **Точность замеров**: Используется `time.monotonic()` для защиты от влияния синхронизации системного времени.
* **Отказоустойчивость**: Реализована обработка сетевых исключений, таймауты (`timeout=15`) и защита от деления на ноль, если все запросы завершились сбоем.
* **Обход кэширования**: К каждому запросу динамически добавляется уникальный параметр `?cache_bust=...`, чтобы исключить получение закэшированного ответа от промежуточных прокси-серверов или CDN.

## Требования
* Python 3.7+
* Зависимости из файла `requirements.txt` (пакет `requests`)

## Установка

1. Склонируйте репозиторий или скопируйте файлы скрипта в отдельную папку.
2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

Вы можете запустить скрипт со стандартными параметрами (значения по умолчанию берутся из `constants.py`):
```bash
python speed_test/main.py
```

Или передать собственные параметры через аргументы командной строки:
```bash
python speed_test/main.py --url "https://example.com" --rounds 10
```

### Параметры CLI:
* `--url` — прямая ссылка на тяжелый файл/картинку для скачивания.
* `--rounds` — количество последовательных запросов (итераций теста).
